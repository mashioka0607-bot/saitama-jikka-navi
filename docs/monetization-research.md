# 収益化リサーチ

最終確認: 2026-09-12

## 採用候補

### ASPBANK / エコスマイリー（不用品回収・出張買取）
- 成果地点: 見積依頼
- 公開報酬: 1,000円 / 1成果
- Web掲載: 可
- 提携: 即時提携と公式サイトに記載
- 一次確認: https://www.aspbank.jp/
- 判断: **補助CTA候補。主力にはしない。** 実家じまいユーザーとの意図整合は高いが、1件1,000円では不動産売却・買取系の高単価導線を置き換えるほどではない。
- 実装条件: ASP登録後に実際の広告リンク、対象地域、否認条件、重複成果条件を管理画面で再確認してから `site_data.json` に追加する。
- 配置候補: 「片付けが必要と確定した後」の記事・診断結果のみ。トップページの主CTAにはしない。

## 収益導線の優先順位
1. 不動産売却・買取・相続不動産の高単価送客（主力候補）
2. 状況診断 → 必要な専門業者への送客
3. 不用品回収・出張買取（補助収益）
4. 低意図の汎用広告は原則置かない

## 運用ルール
- 公開報酬だけで採用せず、クリック→成果→承認までのEPCで比較する。
- 未提携・URL未設定の案件は公開ページに表示しない。
- 地名差し替えだけのページを増やさない。
- 自治体一次情報、ユーザー状況、出口判断が実質的に異なる地域だけ展開する。
