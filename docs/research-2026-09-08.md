# SEO / monetization validation — 2026-09-08

## Decision
Do not publish additional thin location pages. Keep the main conversion thesis: **decide the home's exit before paying for a full clean-out**.

Preferred flow:
1. Confirm inheritance/title and public consultation options.
2. Compare sell / rent / manage / demolish while belongings remain.
3. Obtain an as-is property valuation where appropriate.
4. Only then decide what should be sold, removed or professionally cleared.

## Monetization
Primary monetization should remain property-sale valuation because it is closest to the user's high-value decision. Public third-party ASP data observed on 2026-09-08 lists クラモア不動産売却 via afb at ¥4,230 per conversion, but this is **not an approved/verified account-level condition**. Do not hard-code the amount until the ASP dashboard confirms the current payout, conversion point and rejection conditions.

Secondary monetization (buyback / clean-out) should not interrupt the property-exit decision. Place it after the valuation/exit explanation or where the visitor has explicitly chosen disposal.
