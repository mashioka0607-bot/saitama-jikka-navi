# 2026-09-09 解体導線の収益化調査

## 結論
売却査定だけを主導線にせず、ユーザーが「解体して売る／古家付きで売る」を比較する段階に、解体見積もりを第2収益導線として追加する価値が高い。

ただし、先に解体を勧めない。サイトの原則は「現況査定→手残り比較→必要なら解体見積もり」を維持する。

## SERP/競合
川越の片付け業者は既に「残置物整理→売却・解体」まで訴求。全国系の空き家片付けサイトも「売却・管理・解体」を一体化している。したがって、単なる片付け業者比較や「片付け前査定」だけでは差別化不足。

差別化は「最終手残り」で比較すること。

概念式:
売却見込額 - 片付け費 - 解体費 - 売却諸費用 - 保有継続コスト

これで以下を比較する。
1. 残置物ありのまま売る
2. 家財だけ片付けて売る
3. 解体して土地として売る
4. 当面管理する／貸す

## 自治体一次情報

## 収益導線
1. 相続・名義確認
2. 現況の売却査定
3. 売却価格だけでなく手残り比較
4. 解体が合理的なケースだけ解体見積もりCTA
5. 売れる家財は買取
6. 残りを適法に処分

Primary: 不動産売却査定
Secondary: 解体見積もり
Tertiary: 家財買取・片付け

## サイト品質 P0
現行 build.py には以下が残っている。
- ASP URL未設定でも「準備中」CTAを公開出力
- 広告リンクがないページでも広告注記を表示
- affiliate_click が dataLayer.push のみ

新規記事追加より先にこの3点を直す。

## GSCで次に見るもの
query x page で以下を確認。
- 実家 + 解体 + 売却
- 古家付き + 売却 + 解体
- 空き家 + 解体 + 見積もり
- 実家 + 片付け + 売却

判断基準:
- impressionsが出る語を優先
- 8〜30位で表示されるページは意図一致と内部リンクを改善
- 上位表示してCTRが弱いページはtitle/descriptionを改善
- 表示ゼロの地域語は量産しない
