# 収益化優先順位 — 2026-09-24

## main実装監査で判明したこと

- `build.py` の主ナビは現状 `ホーム / 進め方診断 / 見積チェック / FAQ`。
- main のコード検索では `kaitai-check` / `tedori` が見つからない。過去に検討した「手残り比較」「契約前チェック」は、少なくとも現在のmainでは実装済みとみなさない。
- `offer_cta()` は `site_data.json` の `offers` が空なら表示されない設計。案件条件を確認せず広告を差し込まない。

## 勝ち筋

競合はすでに「片付け前査定」「仲介 vs 買取」「手残り比較」「地域ガイド」「訳あり不動産業者DB」まで実装している。これらを薄く追随しない。

本サイトは **契約・解体・片付けの前に、不可逆な損を防ぐ監査導線** を主軸にする。

特に埼玉県の一次情報では、解体・改修工事は規模を問わず石綿含有建材の事前調査が必要で、発注者にも設計図書提供・調査費用負担等の協力責務がある。また県は解体工事業の登録届出を受け付けている。したがって「見積額」だけでなく、契約前に登録・石綿調査・補助制度・再建築可否等を確認する価値がある。

## P0 実装

1. `/kaitai-check/` を実装する。
   - 解体業者の登録/許可確認
   - 石綿事前調査の有無・費用・結果説明
   - 自治体補助金は「契約前申請」条件の有無を自治体一次情報で確認
   - 解体後の固定資産税・再建築可否を確認
   - 残置物、境界、引渡し条件を売却契約と混同しない
   - 一次情報リンクと「自治体・物件ごとに条件が異なる」注記
2. 主ナビから `/kaitai-check/` に直接リンクする。
3. トップの主張を「片付け前に出口比較」だけでなく「契約前に失う選択肢を確認」へ寄せる。
4. Search Consoleで `解体 契約前 補助金`, `空き家 解体 アスベスト`, `解体業者 登録 埼玉`, `空き家 解体 再建築` の query×page を検証する。

## P1 収益導線

- 査定ASPを置く場合も、契約前チェック完了後の「売却意思が固い層」へのCTAを優先。
- ASP公開報酬だけで決めず、承認条件・否認条件・対象物件・対応地域・成果地点を確認する。
- 十分な高単価案件がなければ `offers: []` を維持し、直接提携用の高意図リード獲得を先に検証する。
