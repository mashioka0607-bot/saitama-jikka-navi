# 収益化リサーチ 2026-09-12 08:04 JST

## 今回の判断変更
自治体一次情報を載せた地域ページ自体は、もはや十分な差別化ではない。競合「家じまいくん」が越谷市ページで、相続登記→除却補助→相場→売却の順番、補助上限、法務局、空き家率、空き家バンクまで具体化している。

したがって本サイトの moat は「自治体情報の掲載」ではなく、ユーザー状態から次の一手を変える実務ナビに置く。

## /shindan/ P0仕様
入力:
- 親: 存命 / 死亡
- 現況: 居住 / 施設入居 / 空き家
- 名義・相続登記: 済 / 未 / 不明
- 残置物: 多い / 少ない / なし
- 出口意向: 売却 / 保有 / 未定
- 現地対応: 可能 / 遠方

出力:
1. 今やること3つ（順序付き）
2. やってはいけない先回り（例: 売却価格確認前の高額片付け・解体）
3. 該当自治体の一次情報
4. 次の収益CTA（売却査定を主、片付けは必要時のみ）

## コンテンツ方針
- 地名差替え量産は禁止。
- 新しい市ページは「固有制度・補助・相談窓口・処分ルール・空き家バンク条件」のうち複数に実差分がある場合のみ。
- 情報ごとに一次URL・確認日・対象条件を持つ。
- 記事PVより diagnosis_complete → affiliate_click → 成果確定率を優先。

## 収益導線
主導線: 現況のまま不動産売却/買取査定
補助導線: 売却しない、または査定後に必要と判定された場合のみ不用品回収/遺品整理

公開確認済み候補:
- ASPLAY: 不動産特化ASP。ただし公開ページでは個別案件の報酬額・承認条件は確認できないため未実装。
- 既調査のエコスマイリー: 見積依頼1,000円/件は補助導線候補。低単価なので主CTAにしない。

## SERP上の脅威
- 家じまい.com: 埼玉全域、遺品整理×不動産買取ワンストップ。
- 家じまいガイド: 片付け前査定、3問診断、手残り比較、地域ガイド。
- 家じまいくん: 市単位で一次制度・補助・売却順序まで具体化。

結論: 「埼玉に詳しい」だけでは弱い。「その人の状態なら今日何をするか」を一次情報付きで返すことを主力価値にする。
