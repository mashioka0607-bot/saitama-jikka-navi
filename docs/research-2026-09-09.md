# 2026-09-09 収益化レビュー

## 判断変更
「片付け前に査定」だけでは差別化しない。競合がすでに、残置物あり・片付け前査定・仲介/買取・相続登記・出口診断まで一体化しているため。

次の主軸は **売却価格ではなく最終手残りで判断する実家じまい** とする。

ユーザーが比較すべきものを、次の式で統一する。

`想定手残り = 売却見込額 - 片付け費 - 解体費 - 仲介等の売却費用 - 保有継続コスト`

記事を増やす場合も、薄い市区町村ページではなく、この意思決定を助ける一次情報・費用・期限・査定導線が揃うページを優先する。

## 高意図クラスター
優先して Search Console の query × page を確認する候補:

- 相続した実家 何から
- 実家 売却 片付け前
- 空き家 残置物 売却
- 実家 売る 片付け 費用
- 空き家 解体 売却 どっち
- 実家 売却 手残り
- 空き家 買取 仲介 どっち

表示がない語を地名違いで量産しない。表示・クリック・CVの出た意図へ集約する。

- 川越市は2026-06-08更新ページで、空き家について「何から手をつければいいか」から相続・管理・賃貸・売却・解体まで宅建士へ原則無料相談できる窓口を案内している。
- 川越市空き家バンクは売却・賃貸の双方を扱う。
- 川越市は空き家発生の約6割が相続起因と案内している。
- 2026-09-27の市公式「空き家・相続もんだい解決フェスタ」でも実家相続と家じまい・解体がテーマになっている。

よって「片付け業者を探すサイト」ではなく、自治体一次情報を使って出口を決め、必要な場合だけ商用サービスへ進む構造を維持する。

## ASP / 収益導線
クラモア不動産売却について、第三者公開情報では afb 4,230円/成果との記載を確認。ただしASP管理画面の一次条件ではないため、成果地点・否認条件・対象地域・最新単価を確認するまで確定値としてサイトへ掲載しない。

評価は報酬単価ではなく `EPC = 実承認報酬 / 送客クリック` を主指標にする。ASP査定、直接送客、買取、片付け/解体の副導線を同じ基準で比較する。
