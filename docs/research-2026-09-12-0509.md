# 2026-09-12 05:09 JST research update

## 結論

汎用の「売る・貸す・住む・壊す」診断や、3,000万円特別控除だけの診断を主力差別化にしない。

SERP上で以下の専業競合が既に存在するため。
- 家じまいくん: 公的データを使い「売る・貸す・住む・壊す」をAI判定
- 空き家あんしん相談室: 相続空き家3,000万円特別控除を5問＋売却額で診断

埼玉実家片付けナビは「川越市の一次情報を使い、今の状態で次に何をするか」を返す実務ナビに寄せる。

## 次の勝ち筋

### 1. 診断を「出口判定」ではなく「次の一手判定」にする
入力候補:
- 親は存命 / 相続済み
- 施設入居済み / 予定なし
- 名義変更済み / 未確認
- 残置物あり / ほぼ空
- 売却意思あり / 未定 / 保有したい
- 遠方在住か
- 媒介契約を既に締結したか

出力候補:
1. まず確認する公的手続き
2. 今は片付けるべきか、査定を先にすべきか
3. 川越市の該当一次情報
4. 次の商用CTA（査定 / 片付け / 買取等）

特に「媒介契約締結前のみ空き家バンク登録可」という川越市固有の条件は、順番を間違えると選択肢を失うため、診断価値が高い。

### 2. 高意図コンテンツ優先順位
P1: 親が施設入居した後、実家を売る前にやること
P1: 川越市の空き家バンクは使うべき？一般売却との順番
P1: 残置物がある実家は片付け前に査定すべきか
P2: 相続空き家3,000万円控除（単独診断ではなく出口ナビ内の条件分岐として利用）
P2: 遠方所有者の空き家管理 vs 売却

## 収益導線
主導線: 不動産査定/売却・買取
補助導線: 片付け・不用品回収

低単価の不用品回収ASPをファーストCTAにしない。診断結果が「片付け先行」に該当したユーザーだけに出す。

ASP/紹介案件は、Web送客可否・対象地域・成果地点・確定条件・報酬が一次確認できるものだけ公開する。今回、新たに条件まで一次確認できた高単価案件はなし。
