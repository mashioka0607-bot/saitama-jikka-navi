# 2026-09-30 06:05 JST SERP / conversion brief

## 結論
新しい市町村ページは作らない。P0は `/build.py` の県全域化と高意図ナビ、次にASP/GA4開通。

今回のSERPで重要だった差分は、競合「実家じまいナビ」が `家族方針 → 仕分け → 不用品回収/遺品整理 → 空き家維持か売却 → 名義/税` という順序を明示していること。一方、当サイトは **売却可能性がある家では、家財を大量処分する前に名義・家族合意・現況売却/保有の出口を確認する** ことを差別化軸にする。この順序差は、単なる「中立」「無料相談」より明確なUSPになり得る。

## 競合SERP
- 実家じまいナビ: 中立、専門家監修、LINE相談、業者見積への送客。流れは「仕分け/片付け」が「売却判断/名義税」より先。
- 安心実家じまい: 埼玉63市町村、立会い不要、料金相場、写真見積。全域・遠方・価格透明性は差別化しにくい。
- 実家じまいの相談窓口: 全国対応、売却時の仲介手数料0円、士業/専門業者ネットワーク。ワンストップも差別化しにくい。
- 実家じまいログ: 売却・解体・片付けを分けて比較、端末内保存。意思決定ツール競争も進んでいる。

## 高意図キーワード仮説
GSCで query×page を優先確認する。表示実績がなければ専用記事を量産しない。
- 実家 片付けてから売る
- 実家 片付けずに売る
- 空き家 残置物 そのまま 売却 埼玉
- 相続した家 片付ける前 査定
- 実家 売却 片付け前
- 実家 売るか 持つか

## 収益導線
1. 方針未定 → `/shindan/`
2. 売却可能性あり → `/tedori-hikaku/` → 現況査定案件
3. 売却予定なし / 退去期限優先 → 片付け見積案件
4. 民間案件不適合 / 相談段階 → 埼玉県・市町村の公式相談/空き家バンク

片付け案件を売却案件より先に出して高単価CVを食わない。
