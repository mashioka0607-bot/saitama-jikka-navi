# 川越市空き家バンク「媒介契約前」条件の再確認（2026-09-26）

## 判断変更
以前、川越市空き家バンクについて「宅建業者との媒介契約締結前のみ登録可」という条件を一次情報で確認できないとして訴求から外したが、2026-09-26の再確認で川越市公式「空き家を売りたい・貸したい方」に明記されていることを確認した。

公式の登録要件には、登録できる空き家として「宅地建物取引業者と媒介契約が締結されていないこと」が含まれる。
一次情報: https://www.city.kawagoe.saitama.jp/kurashi/jyutaku/1003031/1003032/1003036.html

したがって川越市では、売却を検討する所有者にとって「媒介契約を結ぶ前に空き家バンク適格性を確認する」は実際に選択肢を失わないための高意図・契約前情報になる。

## SERP/競合からの示唆
「査定前に片付け不要」「残置物のまま査定」「仲介 vs 買取の手残り比較」は既に競合が強化しており、同内容の記事追加だけでは差別化しにくい。競合には手取りシミュレーターまで実装したサイトもある。

一方、自治体固有の「契約すると使えなくなる可能性がある公的出口」を一次情報で契約前に提示する設計は、当サイトの『お金を払う/契約する前に損を止める』方針と整合する。

## 高意図キーワード仮説

薄い地名記事として量産せず、川越市で一次情報と不可逆条件が確認できるケースを深く扱う。

## 収益導線
推奨順序は「公的出口の適格性確認 → 現況査定/仲介査定 → /tedori-hikaku/ で費用・期間込み比較 → 売却方針決定 → 成果案件が正式提携できた場合のみ査定CTA」。

川越市空き家バンクは市が直接交渉・契約する制度ではなく、協定団体の宅建業者が媒介する。登録費用はかからないが、契約成立時は媒介報酬が必要と公式に案内されている。

## ASP
タウンライフ空き家解決は2026年4月時点で提携事業者650社超、2026年5月には全国1718市区町村で紹介可能と運営会社が公表しており、サイトテーマとの適合度は高い。運営会社は成功報酬型ASP「タウンライフアフィリエイト」も運営している。ただし、当サイトが現在提携可能か、空き家案件の現行報酬額・成果地点・否認条件は公開情報だけでは確定できないため、報酬額はサイトに書かない。

第三者サイトではLIXIL不動産ショップ空き家買取/felmat 30,800円という2026年9月情報も見つかるが、ASP管理画面・広告主一次情報で未確認なので候補リスト止まり。正式導入判断には使わない。

## Search Console 次の検証
Search Consoleの所有権確認ファイルはリポジトリにあるが、クエリ実測データはこの実行環境から取得できていない。次にデータを取得できたら、/tedori-hikaku/ と /kaitai-check/ を中心に以下を確認する。

1. `片付けてから売る`, `現況買取`, `解体してから売る` の impressions / clicks / CTR / average position
2. `川越市 空き家バンク`, `媒介契約`, `契約前` を含むクエリの発生有無
3. 順位8〜20かつ表示回数があるクエリを優先して既存ページへ追記し、新規地名ページ量産はしない
4. CTA導入後は affiliate_click をGA4で計測し、SEO順位だけでなくクリック率→成果率でページ優先度を決める

## 次の実装候補
ASP/GA4が未接続の間は、/tedori-hikaku/ に川越市向けの「媒介契約前なら空き家バンク適格性も確認」ブロックを追加する価値がある。ただし全国一般論に誤拡張せず、川越市公式一次情報に限定して表示する。
