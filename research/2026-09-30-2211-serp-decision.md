# 2026-09-30 22:11 SERP / monetization decision

## Decision
「片付け前査定」「残置物あり売却」「仲介 vs 買取」「手残り比較」単体は、競合が急速に実装しておりUSPとして弱くなった。今後は **契約前STOP判定 + 売りにくさ判定（再建築不可・接道・共有/相続・借地・老朽化・残置物・遠方） + 出口振り分け** を主軸にする。

## SERP observations
- 家じまいガイド: 片付け前査定、手残り比較、4つの出口診断、仲介vs買取、相続登記STOPまで実装済み。
- 実家とお墓: 「片付けずに売る」と「片付けて仲介する」を最終手取りで比較する記事が2026-09最終週に公開。手残り比較そのものも競争領域化。
- MK-HOME / 空き家パス: 残置物あり・築古・遠方・スピード買取を強く訴求。
- フィリアコーポレーション: 再建築不可・残置物あり等の難物件実績を訴求。
- SA: 残置物、老朽化、行政連絡後などを現況から整理する事例訴求。

## High-intent query cluster to validate in Search Console
優先して query × page を確認する。
1. 相続した家 再建築不可 売却
2. 空き家 接道 売れない
3. 相続 共有名義 家 売却
4. 実家 残置物 そのまま 売却
5. 実家 解体してから売る そのまま売る
6. 空き家 遠方 立会不要 売却

見る指標: impressions / avg position / CTR / landing page。表示が出たクラスターだけ深掘りし、地名だけを差し替えたページは作らない。

## Monetization route
診断結果を「通常仲介向き」「現況買取向き」「専門家/自治体相談を先に」に分ける。ASPは承認済み案件の成果条件を管理画面一次情報で確認できるまでURL・報酬額をコードへ入れない。成果導線は GA4 `affiliate_click` で context と offer を計測する。

## Primary-source guardrail
埼玉県公式（2026-09-28更新）では、利用目的のない空き家は約13万戸、20年間で約1.8倍。県の空き家バンクは「売りたい・貸したい」所有者の公的出口として維持する。

## Engineering priority
P0は変わらない。build.py に残る川越固定 nav / hero / meta / 自治体案内を県全域UIへ直し、回帰テストをPASSさせる。その後 GA4 → 承認済みASP 1件 → GSC実測に進む。存在しない `/tedori-hikaku/` を先にnavへ追加しない。
