# 川越市・自己搬入の一次情報確認（2026-09-06）

## 結論
主力LP `/kawagoe-shi/katazuke-hiyou-urenai/` に入れる費用比較の正本は、川越市「家庭ごみのごみ処理施設への持込み（自己搬入）」とする。

- 一般家庭：10kgにつき50円
- 1回の搬入量が40kg以下：無料
- 50kgの例：250円
- 原則、ごみを出した本人が搬入
- 荷下ろしも原則本人
- 川越市外で発生したごみ、家電リサイクル法対象機器、PC、危険物等は搬入不可
- 受付：月〜金（祝日も受付、年末年始除く）、8:40〜11:50 / 12:45〜16:00

一次情報:
https://www.city.kawagoe.saitama.jp/kurashi/gomi/1002380/1002397.html

## 収益導線への使い方
「自治体処分が最安」と煽らず、次の3分岐を短く提示する。

1. 少量・自力搬出可能 → 市の自己搬入を確認
2. 売れる家財 → 捨てる前にリユース査定
3. 大量・遠方・売却予定 → 片付け費を先払いする前に残置物ありの現況査定

主目的はごみ検索のPV獲得ではなく、売却意図のあるユーザーが不要な全撤去を先払いせず、最終手取り比較へ進むこと。

## SERPメモ
2026-09-06再検索でも、川越市の片付けSERPには遺品整理・不用品回収・空き家片付け業者が並び、「残置物整理」「売却予定に合わせる」訴求が確認できる。当サイトは業者一覧の量産ではなく、自治体一次情報＋売却前の判断順序で差別化する。

## GSCで次に検証
`川越 ごみ 自己搬入` / `川越 粗大ごみ 持ち込み` は補助指標。主評価は `実家 片付け 費用` / `残置物 処分 費用` / `実家 売却 片付け` / `荷物 そのまま 売却`。ごみ系表示だけ増えて不動産出口へのクリックが弱ければ、自治体ごみ記事は拡張しない。
