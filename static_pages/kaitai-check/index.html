解体契約の前に

実家は「先に解体」が正解とは限りません

解体費だけでなく、現況査定、補助金の申請順、アスベスト事前調査、固定資産税等の住宅用地特例、再建築可否まで確認してから出口を比較してください。

2026年度の重要更新：上尾市の受付終了、川口市の期限、白岡市の対象外費用

上尾市：2026年10月13日に予算到達で受付終了。市の当初申請期限は10月30日ですが、2026年度分の新規申請は終了と発表されています。補助金を受け取れる前提で契約せず、売却・買取・管理も含めて検討してください。上尾市公式（受付終了のお知らせ）

川口市：事前診断の依頼は2026年10月30日、交付申請は11月13日、工事完了報告は2027年1月29日まで。通常の空き家が一律対象ではなく、主に無接道・再建築困難な不良住宅等の限定条件があります。予算到達で早期終了する可能性もあるため、申請前に対象・受付可否を市へ確認してください。川口市公式（空家除却補助金）

白岡市：2026年10月13日時点の予算残額は30万円（満額支給なら残り1件分）。市公式の補助対象経費は建物の除却工事と工事廃材の撤去・処分であり、家財道具の処分費用は対象外です。「解体補助で家財処分も賄える」と見込まず、家財処分費と解体費を分けて、現況売却との最終手残りで比較してください。予算残額は10月13日時点の公表値で、現在の受付可否は未確認です。白岡市公式（空家等除却補助金）

白岡市：解体後の固定資産税等にも別の補助制度があります。市の除却補助金を受けた跡地を、更地のまま保有・管理する等の条件を満たす場合、住宅用地特例が外れたことによる固定資産税・都市計画税の差額について、除却年の翌年度から最大2年度の補助を受けられる可能性があります。ただし予算・対象地・所有者変更・申請期限の条件があるため、解体後すぐに売却する場合は受給を前提に手残りへ加算しないでください。白岡市公式（解体後の固定資産税等相当額補助）

2026年10月27日に自治体の公式公表内容を再確認。期限内でも当日の受理・予算残額を保証するものではありません。制度変更や翌年度の受付状況は必ず公式ページで確認してください。

自治体を選んで「今、契約してよいか」確認

2026年度の一次情報を確認済みの自治体だけを掲載しています。補助金は交付決定前の契約で対象外になる場合があります。

解体前に確認する6項目

  1. 建物付きの現況で査定を取る — 解体すれば高く売れると決めつけず、現況売却と更地売却の手残りを比較します。
  2. 自治体の補助制度を契約前に確認する — 制度によっては交付決定前の契約・着工で対象外になります。
  3. アスベスト事前調査を見積条件に入れる — 埼玉県は、建築物・工作物の解体・改造・補修では規模にかかわらず、工事部分の全材料について石綿含有建材の有無を工事前に調査する必要があると案内しています。解体工事部分が80㎡以上の建築物などは事前調査結果の報告も必要です。
  4. 固定資産税等と再建築可否を確認する — 解体で住宅用地の軽減が外れる場合や、土地条件によって再建築できない場合があります。
  5. 補助対象費と対象外費を分ける — 家具・家財など動産の処分費が補助対象外になる自治体があります。
  6. 許可・登録と追加費用条件を揃えて見積比較する — 工事範囲、アスベスト調査・分析費、追加費用、補助制度の施工業者要件を同条件で比較します。

アスベストは「古い家だけの任意チェック」ではありません

埼玉県の2026年8月27日更新情報では、解体等工事の元請業者または自主施工者が、規模の大小にかかわらず工事前に全ての材料を事前調査します。書面調査と現地の目視調査が必要で、それでも含有の有無が不明なら分析調査が必要です。

見積時に確認：「石綿事前調査は見積に含まれるか」「分析が必要になった場合の追加費用はいくらか」「80㎡以上の解体なら結果報告を誰が行うか」を確認しておくと、契約後の想定外費用を減らせます。

見積先は埼玉県の公式名簿でも確認

埼玉県は、県内で解体工事を行う事業者には原則として県知事の解体工事業登録が必要で、1件500万円以上の工事では建設業許可が必要と案内しています。県は登録業者名簿も公開しています。

契約前チェック：会社名・所在地を公式名簿と照合 → 補助制度の施工業者要件を確認 → 工事範囲・アスベスト調査費・追加費用条件を揃えて比較。

補助金があっても「先に契約」は危険

2026年度のときがわ町老朽空き家除却補助金は、補助対象工事費の2分の1（上限40万円、町内業者なら上限50万円）ですが、家具・調度品の処分費は対象外です。町は交付決定前に工事契約をすると補助を受けられなくなると明記しています。受付は2026年12月25日までですが、予算到達で終了します。

実務上の順番：自治体へ事前相談 → 現況査定 → 補助対象/対象外費を確認 → アスベスト事前調査を含む条件で見積取得 → 申請・交付決定 → 契約・着工。

解体以外の出口も先に比べる

  • 売る：建物付き現況と更地の両方で手残りを比較。
  • 貸す：修繕・管理費まで含めて比較。
  • 残して管理：維持費と管理責任を確認。
  • 解体：上の確認を済ませ、解体後の利用・売却方針まで見えてから契約。

売る予定なら「売値」より手残りで比較

現況のまま売る場合と、片付け・修繕・解体をしてから売る場合では、先に出る費用と売れるまでの維持費が変わります。
