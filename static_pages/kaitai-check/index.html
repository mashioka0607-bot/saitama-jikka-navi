解体契約の前に

実家は「先に解体」が正解とは限りません

更地は売りやすくなる場合がありますが、解体費だけでなく固定資産税等の住宅用地特例や再建築可否、補助金の申請順にも影響します。まず現況のまま出口を比較してください。

解体前に確認する5項目

  1. 建物付きの現況で査定を取る — 「解体すれば高く売れる」という前提を置かず、現況売却と更地売却の手残りを比較します。
  2. 自治体の補助制度を契約前に確認する — 制度によっては交付決定前の契約・着工で対象外になります。見積取得と契約は別物として扱ってください。
  3. 固定資産税等と再建築可否を確認する — 解体で住宅用地の軽減が外れる場合や、土地条件によって再建築できない場合があります。
  4. 補助対象費と対象外費を分ける — 解体補助があっても、家具・家財など動産の処分費は対象外の自治体があります。片付け費と建物解体費を見積書でも分けて確認します。
  5. 許可・登録と追加費用条件を揃えて見積比較する — 解体方針が固まってから、必要な許可・登録のある事業者を候補にし、工事範囲、追加費用、補助制度の施工業者要件を揃えて比較します。

補助金があっても「先に契約」は危険

2026年度のときがわ町老朽空き家除却補助金は、補助対象工事費の2分の1（上限40万円、町内業者なら上限50万円）ですが、家具・調度品の処分費は対象外です。さらに町は、補助金の交付決定前に工事契約をすると補助を受けられなくなると明記しています。受付は2026年12月25日までですが、予算到達で終了します。

鴻巣市も、解体工事費の3分の1・上限30万円の制度で、家財等の動産処分費と消費税等を補助対象から除外し、交付決定後に行う工事であることを条件にしています。

実務上の順番：自治体へ事前相談 → 補助対象/対象外費を確認 → 現況査定 → 見積取得 → 申請・交付決定 → 契約・着工。自治体ごとに条件は異なるため、必ず対象物件の自治体で確認してください。

解体以外の出口も先に比べる

「使わない家＝解体」ではありません。売却・賃貸・管理を含めて比較してから、不可逆な解体を決めるのが安全です。

  • 売る：建物付き現況と更地の両方で手残りを比較する。
  • 貸す：川越市は相続等で住まない住宅について、公的な「マイホーム借上げ制度」を案内しています。埼玉県内の物件は年齢要件が緩和されています。
  • 残して管理：川越市はシルバー人材センターと空き家管理で連携しています。売却時期を急がない場合の選択肢です。
  • 解体：上の確認を済ませ、解体後の利用・売却方針まで見えてから見積もります。

川越市の一次情報で確認する

川越市は解体のメリットとして「管理の手間がなくなる」「土地が売却しやすくなる」、デメリットとして「解体費用」「住宅用地の固定資産税等の減税措置が適用されなくなる」「解体後に再建築できない場合がある」を案内しています。また、市と宅建協会の相談窓口では相続・管理・賃貸・売却・解体まで相談できます。

売る予定なら「売値」より手残りで比較

現況のまま売る場合と、片付け・修繕・解体をしてから売る場合では、売却価格だけでなく先に出る費用と売れるまでの維持費が変わります。
